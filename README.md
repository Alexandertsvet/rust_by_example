# SmartHome

`smart_home` — библиотека для моделирования умного дома и автоматизаций.

Позволяет создавать устройства (термометры и розетки), объединять их
в комнаты, а комнаты — в дом, а также получать отчёты о состоянии
всей иерархии.

## Основные возможности

- Создание устройств умного дома: `SmartTermometr` и `SmartSocet`.
- Объединение разнотипных устройств в `SmartDevice`.
- Создание комнат (`Room`) с именем и списком устройств.
- Создание дома (`SmartHouse`) с именем и списком комнат.
- Доступ к комнатам и устройствам по индексу (включая мутабельную ссылку).
- Вывод отчётов по отдельному устройству, комнате и дому целиком.
- Утилита `get_random_number` для генерации случайных чисел в диапазоне.
